# 多平台业务自动化工作台 v1.0.0

把您在**多个业务平台**上的**下载 / 上传流程**录一遍，之后一键或定时自动执行。
浏览器操作录制器 + 回放引擎 + 多平台管理，全部本地运行，数据不出浏览器。

## 一、安装（Chrome / Edge）

1. 打开浏览器 → 地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录（含 manifest.json 的文件夹）
4. 点击工具栏扩展图标 →「打开侧边栏」即出现控制面板

> 首次使用「上传」功能时，浏览器顶部会出现"xxx 正在调试此浏览器"提示条，属 CDP 正常现象，允许即可。

## 二、快速上手（30 秒）

1. **新建平台**：面板 →「＋ 新建平台」→ 填平台名称、入口网址、下载目录、上传目录
2. **录制流程**：点平台卡片上的「● 录制下载/上传」→ 点「开始录制」→ 在目标网站**正常操作一遍**（点击/输入/选择/上传/下载）→ 回面板点「停止录制」→ 保存
3. **执行**：点「▶ 执行下载/上传」，流程自动跑，任务区实时显示进度与日志

## 三、核心能力

| 能力 | 说明 |
|---|---|
| 操作录制 | 监听点击/输入/下拉/勾选/上传/下载/页面跳转，自动生成步骤 DSL |
| 智能定位 | 每个元素存 6 级定位器（id→属性→class→文本锚→路径），页面小改版也能找到 |
| 断点续跑 | 整页跳转会销毁页面脚本，引擎自动等待加载完成后从断点继续 |
| 失败容错 | 单步失败自动重试 2 次，仍失败跳过并记录快照，流程不卡死 |
| 下载归档 | 流程执行期间产生的下载自动归入平台「下载目录」 |
| 上传 | 通过 CDP 自动设置本地文件；文件缺失/页面不兼容时降级为手动选择 |
| 定时轮询 | 平台可配置轮询间隔（分钟），到期自动执行指定流程 |

## 四、录制要点（决定回放成功率）

- **登录态**：录制和回放都在同一浏览器，登录态自动保持；如平台登录会过期，请先录制「登录」流程或在回放前手动登录
- **操作顺序**：真实操作顺序即录制顺序，输入后请继续下一步（录制器会正确排序）
- **不要录**：临时弹窗、验证码、拖动排序等录制器不支持的交互
- **下载识别**：页面链接/按钮文本含"下载/导出"或为文件链接（.pdf/.xlsx 等）会自动标记为下载步骤

## 四、变量与编辑

录制生成的步骤可在面板文本框中直接编辑（JSON），常用字段：

```json
{ "action": "input", "target": [{"kind": "css", "value": "#ticketNo"}], "value": "{{ticket}}" }
```

- `{{变量}}` 占位符（如 `{{ticket}}`）暂未在面板提供变量管理入口，可在「编辑平台」中预留或直接写死
- 步骤类型：`goto` / `click` / `input` / `select` / `checkbox` / `upload` / `download` / `key` / `wait` / `assert`
- 每步可加 `"wait": {"type": "url|element|text|time", "value": "..."}` 控制执行后等待条件

## 五、测试方式

本地测试台验证（无需真实平台）：

1. 启动任意静态服务指向项目根目录（如 `python -m http.server 18080`）
2. 浏览器打开 `http://127.0.0.1:18080/work/test-page.html`
3. 按「快速上手」流程：新建平台（入口地址填测试台 URL）→ 录制 → 执行，观察任务区日志

已通过的自动化验证：选择器 8 项 / DSL 4 项 / 录制 6 类事件（含顺序与防抖）/ 回放 5 步全通过 + 失败跳过容错。

## 已知限制（v1.0.0）

- 下载自动归档使用 `chrome.downloads` 的 suggest 路径（相对默认下载目录的子路径）；如需任意盘绝对目录需后续接本地助手
- 「上传」依赖 CDP（debugger 权限）；DevTools 打开时 CDP 冲突会自动降级为手动上传
- 浏览器重启后等待中的任务需手动重跑（内存态不持久化）
- 跨域 iframe 内的操作需站点支持 frame 注入（host_permissions 已含 <all_urls>，主流平台可注入）
